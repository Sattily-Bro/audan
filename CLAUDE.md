# Audan.kz — редизайн городского супер-аппа (бывш. raion.kz)

Городской портал г. Шу, Казахстан. Мы (дизайн-подрядчик) делаем новый фронт;
заказчик («владелец») добивает бэкенд своим Claude Code. Живой сайт: https://www.raion.kz

## Роли и договорённости
- **Мы** отдаём код фронта через git. Вёрстка/UX — наша зона, бэкенд — владельца.
- **Источник истины по API** — приватный репо `kulnurzhan/raion-handoff`, клонирован в `./raion-handoff/`.
  Читай `raion-handoff/HANDOFF.md` (§3 роуты, §4 словари JSON, §6 статусы) и `raion-handoff/src/*.jsx`
  (старый фронт — источник поведенческой логики, но **ни строчки кода из него не переносим**).
- API: `POST /api/?r=<group>.<action>`, JSON-тело, cookie-сессия, ответ `{ok:true|false}`.
  Картинки: `GET /api/?r=image&id=N` (BLOB из MySQL, один размер).
- **Запросы к бэку (ещё не согласованы с владельцем):** варианты размера картинок
  (`&w=400` + `Cache-Control: immutable`), курсорная пагинация списков, разрез `home.summary`.
- Бэкенд поднимается локально на sqlite: `raion-handoff/HANDOFF.md` §9, `db/schema.sqlite.sql` + `seed.php`.

## Состояние дизайна (готово)
- Выбран **Вариант 12 «Платформа»**: дисциплина Kaspi, поиск сверху, в шапке «Audan.kz» и «Shu»
  (продукт масштабируется на другие районы — топонимы всегда данные, не лейблы).
- **38 экранов** собраны в интерактивный юзерфлоу: `design/flow.html`
  (десктоп — Figma-подобный канвас со стрелками и инспектором; телефон/узкое окно — кликабельный
  прототип). Прототип «боевой»: **всё кликабельно, без демо-тостов** — общий стейт (корзина,
  избранное, голоса, отклики), живой поиск по всем разделам, корзина → Kaspi-оплата → трекинг,
  комментарии/посты публикуются, кабинет заведения гоняет заказы по статусам, шторки-пикеры вместо системных
  диалогов. Поиск контекстный (в Еде ищет еду, в Базаре — объявления), меню кафе — реальными
  секциями с блюдами, фильтры списков — по словарю категории, сортировка — Kaspi-шторкой,
  страница работодателя в духе hh. Фотографии (Unsplash/Flickr CC) в `design/src/img/`,
  сборка вшивает их data-URI (flow.html ≈ 3.3 МБ).

- **Палитра не финализирована**: 13 свотчей в шапке flow.html (дефолт «Кобальт» #2450D8;
  кандидаты владельца: #334D86 «Стальной», #49619D «Сине-серый», оранжевые). Выбор за заказчиком.
- Шрифт **Inter** (вшит в страницы data-URI, сабсеты latin+cyrillic+cyrillic-ext — казахские
  Ә Ғ Қ Ң Ө Ұ Ү І покрыты). Нейтрали намеренно тёплые (#F7F6F2 фон, #8B887F серый текст).
- Иконки — заказной пак (155 шт, `design/src/icons/`), спрайт `icons-sprite.svg` вшивается

  одна на всё приложение (`#share`).

## Как править экраны (ВАЖНО)
`design/flow.html` и `design/04-screens-v12.html` — **собранные артефакты, руками не править**.
Исходники: `design/src/audan-screens.html` (все экраны секциями `<!-- S0: -->…<!-- S35: -->`),
`design/src/flow-shell.html` (оболочка канваса: раскладка POS/EDGES, описания SCREENS, проводка
data-go/data-back/data-sheet, интерактив), сборка: `python3 design/src/build.py`.
После правок проверяй баланс `<div>` по секциям — билд не прощает незакрытые теги.

## Ключевые UX-решения (не откатывать без владельца)
- Таб-бары контекстные, ровные (без FAB): первым пунктом всегда «Главная»;
  базар/еда/работа/лента/карта несут свои 3–4 вкладки; карточки товара/меню/формы — без бара.
- Активный заказ еды — строкой на главной и в еде; тап → `/order/{id}`.
  **Оплата по счёту Kaspi** (решение владельца, 19.08.2026): клиент указывает номер Kaspi при
  оформлении → заведение принимает заказ → «Счёт выставлен» → клиент переводит и жмёт «Я оплатил»
  → заведение «Оплата пришла» → готовится → едет → доставлен. Списания при оформлении нет,
  «отменить» кнопки нет — только звонок. Полностью расписано в `design/FOOD-ORDER-FLOW.md`.
- Категории базара: плоские 3×3 без групп; вложенность (Живой скот, Спецтехника) → субкатегории
  того же дизайна. Поля объявления — словарь `SECTION_FIELDS`, обязательность из `meta.ads_field_req`.
- Еда — анатомия Glovo; отзывы заведений — отдельная страница, отзыв только после заказа.
- Лента: лайк И дизлайк (post_votes хранит оба — сохранено из старого кода).
- Авторизация: **вход и регистрация — разные экраны**. Вход — **только по номеру телефона**
  (входа по e-mail нет), дальше SMS-код. Регистрация: имя, телефон, **номер WhatsApp**
  (по умолчанию совпадает с телефоном) и **пароль не короче 6 символов**, ниже явные галочки
  согласий (оферта, правила, перс. данные — обязательны; рассылка — по желанию);
  кнопка неактивна, пока не заполнено и не отмечено. Дальше: SMS-код → PIN → диалог Face ID.
- Главная: шапка «Audan.kz» + «Shu» синим тегом (белый текст, без переключателя района);
  справа от колокольчика — переключатель языка ҚАЗ/РУС дропдауном (синхронен с выбором в профиле).
  Лента — «Новые объявления». В категориях базара чипа «Мои объявления» нет — внизу есть таб «Мои».
- Stories открываются сразу картой (кнопки ←/→ по фото, крестик — выход), «Сеткой» — лента.
- Профиль: секция «Рабочий кабинет» (ресторан / объекты карты / мои объявления).
- Кабинет заведения: заказы по срочности с таймерами, тумблер «Принимаем заказы»,
  сегменты Новые · Ждут оплаты · Готовятся · У курьера.
- **Карта** (UX 2ГИС, правка 20.08.2026): открывается чистой — карта с точками, **поиск в нижнем
  доке** над постоянным меню «Главная · Карта · Избранные · Добавить», над доком — чипы категорий.
  Тап по поиску → **полноэкранный поиск**: квадратные карточки категорий слайдером, история
  с крестиками, рекламное место (2ГИС). Запуск поиска / выбор категории → запрос уезжает
  в пилюлю сверху (тап по ней возвращает в поиск), док прячется, снизу свайп-шторка:
  шапка «заголовок + крестик», ниже единый ряд чипов «Фильтры · Открыто · Рядом · Доставка ·
  Круглосуточно» (все рабочие); «Фильтры» открывает **свой экран** (Сбросить · Готово; Важное /
  Рейтинг ≥N / Сортировка), активные фильтры считаются в чипе («Фильтры · 2»). Видна первая
  карточка и половина второй (4-5 квадратных фото слайдером, метка видео); свайп вверх — весь список;
  тап по фото в карточке списка открывает место, свайп ленты — нет. Свайп/тап по ручке дока — «Все места».
  Тап по точке → карточка места на **четверть экрана** (имя, тип, рейтинг, «Открыто», кнопки);
  свайп вверх (промежуточного снапа нет) — полная карточка прямо в шторке: фото сверху
  (при скролле уезжают, шапка липнет), возможности, адрес, контакты, отзывы — кнопки
  «Вся информация» нет, экран /place остался эталоном для deep-link (obj.php); тап по фото — лайтбокс.
  Шторка примыкает к меню без зазора; свайп вниз из места, открытого из списка, возвращает к списку,
  крестик полноэкранного поиска не сбрасывает результаты. Снапы: скрыта → 25% → список → полная
  (полная — от высоты экрана, не фикс-px). Шторки «Позвонить»/«WhatsApp» берут номер из контекста
  (data-ph / телефон места, заведения, работодателя, курьера).
  Сердце в карточке кладёт место в «Сохранённые». В Stories-карте — кнопка «Выйти».
- **Добавление места** — единая форма (`/map/new`) для всех кнопок «Добавить»: точка на карте
  обязательна, отправка уходит **на модерацию**, статусы видны в «Моих объектах» (на проверке /
  на карте с просмотрами / отклонён с причиной и кнопкой «Исправить»).
- Наши отступления от старого кода (озвучены владельцу): форма подачи в 3 шага;
  Работа+Подработка одним экраном; глобальные таб-бары вместо секционных.

## Audan Live (редизайн раздела, начат 28.09.2026)
Бриф владельца: `~/Downloads/design-brief-audan-live.md` (дизайн-система раздела **отличается** от нашей:
акцент #0F5FCC, шкала шрифта 11/12/13/14/15/16/17/20/22/28, радиусы 12–22, значки без подложек, язык по умолчанию — казахский).
Прототип `design/live.html` (32 экрана: флоу + состояния §6), логика/порядок/новые данные — `design/LIVE-SPEC.md`.
Концепция (правка 30.09.2026, по замечанию «не копировать инсту»): раздел о **местах, а не аккаунтах** —
«Места» (горячие точки) вместо колец людей, кольцо-таймер 24 ч у поста, просмотрщик места, два вида ленты
(карточки / сетка-masonry с поиском и «Лучшим за неделю»), **подписки** и сегмент «Все · Друзья» в ленте и на карте,
на карте пост — полуэкранная шторка-карусель (фото сверху, соседи по бокам, бесконечно), официальный ответ округа в «Дорогах».
Таб-бар раздела: Главная · Live · Карта; «Мой Live» — по аватару в шапке. Экранов — 32.
Исходники `design/src/live/`, собирается тем же `build.py`. Жёсткие правила: одна живая Яндекс-карта на экран
(остальные — статичные картинки), ≤60 меток без анимации, © Яндекса видно, «…» с жалобой/блоком у каждого поста и
комментария, звук видео только по тапу, без эффектов нажатия. Казахские тексты — рабочие, нужна вычитка.

## Текущий большой этап — репозиторий фронта (`app/`, начат 20.08.2026)
**Все 38 экранов портированы** (auth, главная, базар, еда с Kaspi-счётом, карта 2ГИС,
работа/мастера, лента/stories, профиль/кабинет). Смоук: 37 маршрутов без ошибок,
сквозные флоу проверены (вход по SMS, заказ еды до «Оплата отмечена» через кабинет владельца,
карта: категория → шторка → фильтры → место). Экраны — ленивые чанки. Git: репо в корне
~/audan (raion-handoff и генерируемые выдачи в .gitignore). Запуск/структура: app/README.md.
Каркас: Vite + React + TS + Tailwind v4 (токены прототипа в `src/styles/app.css`,
13 палитр в `src/theme/palettes.ts`), React Aria Components, React Router (пути = deep-links),
API-слой `src/api/` (client по HANDOFF §2, типизированные роуты §3, типы данных §4/§6),
MSW-моки (`npm run dev:mock` — работа без PHP-бэка; с бэком — `npm run dev`, прокси на :8000),
спрайт иконок вшивается (`src/ui/Icon.tsx`; id форм не должны совпадать с id иконок).
Портирован вертикальный срез: экран входа S16 (маска +7, auth.phone_start → /otp).
Остальные экраны — по эталону `design/src/audan-screens.html`, роуты уже разведены в
`src/app/router.tsx` (заглушки Pending — маркеры порта, в финальной сборке недопустимы).

Стек (согласован в этом проекте): **Vite + React + TypeScript + Tailwind v4**,
headless-примитивы React Aria Components, MSW-моки + локальный sqlite-бэк, PWA + Capacitor
(обёртки уже есть в raion-handoff: `android/`, `ios/`, `capacitor.config.json`).
TS-типы API генерировать из PHP-роутов raion-handoff, не из наблюдений.
Не сломать: OG/deep-links (`ad.php`, `post.php`, `obj.php`…), FTP-деплой владельца, `/api/` и `/panel/`.
Дизайн-эталон каждого экрана — соответствующая секция `design/src/audan-screens.html`.
