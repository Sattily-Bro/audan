# design/ — дизайн-концепты и интерактивный юзерфлоу Audan.kz

## Показ заказчику
```bash
cd design && python3 -m http.server 8080
# → http://localhost:8080/flow.html   (главный артефакт)
# с телефона в той же сети: http://<IP-мака>:8080/flow.html
```

## Правила
- Один акцент через CSS-переменные `--acc*` — палитры переключаются свотчами (13 шт, дефолт Кобальт).
  Финальный цвет выбирает владелец; новые палитры добавлять в `PALETTES` в flow-shell.html.
- Данные в экранах настоящие (raion.kz + raion-handoff): цены, посты, рестораны, мастера.
  Демо-контент допустим только там, где живых данных нет, и должен быть правдоподобен для Шу.
- Никаких «демо»-тостов и системных заглушек: каждый тап ведёт на экран, шторку или меняет
  состояние. Действия, уходящие из приложения (WhatsApp, звонок, маршрут), — стилевые шторки.
- Топонимы («Шу», «Кордай») — только контентом, никогда в лейблах фиксированной ширины.
- После правки исходников: собрать, проверить в билд-логе баланс тегов, прогнать ключевые
  переходы в презентации (фильтры базара, степперы меню, otp→pin→FaceID).
